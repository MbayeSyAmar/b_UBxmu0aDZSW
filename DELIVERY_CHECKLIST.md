## 🚀 TO LAUNCH IN 3 STEPS

### Step 1: Setup (5 minutes)
```
1. Visit sanity.io → Create account
2. Create project named "CRMTN"
3. Go to Settings → API → Tokens
4. Create token called "CRMTN Website"
5. Copy your PROJECT_ID and TOKEN
```

### Step 2: Configure (5 minutes)
```
Create file: .env.local

NEXT_PUBLIC_SANITY_PROJECT_ID=your_id
NEXT_PUBLIC_SANITY_DATASET=production
SANITY_API_TOKEN=sk_production_xxx
```

### Step 3: Launch (2 minutes)
```bash
npm run dev

# Visit:
# http://localhost:3000 (website)
# http://localhost:3000/studio (CMS)
```
