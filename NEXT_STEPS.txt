ÉTAPE 1: Créer compte Sanity gratuit
  → Allez sur: sanity.io
  → Sign up (2 min)
  → Créez un projet "CRMTN"
  → Notez: PROJECT_ID + DATASET

ÉTAPE 2: Créer .env.local (à la racine du projet)
  NEXT_PUBLIC_SANITY_PROJECT_ID=your-id-from-sanity
  NEXT_PUBLIC_SANITY_DATASET=production
  SANITY_API_TOKEN=your-token-from-sanity

ÉTAPE 3: Installer packages
  $ npm install

ÉTAPE 4: Lancer le serveur
  $ npm run dev

ÉTAPE 5: Accéder au studio
  → http://localhost:3000/studio
